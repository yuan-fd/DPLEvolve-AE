# Claims-to-executions mapping

This page maps paper claims to commands that execute the relevant experiment.
The compact files under `artifacts/*/expected/` are reference transcriptions;
reading them is an archive audit, not experimental reproduction.

## Table 4: nine-case detailed-placement QoR

The paper compares default OpenROAD DPL, a public-knob Optuna-TPE search, and
two selections from ReviewDSE. All rows use the same protected evaluator and
final post-DPL HPWL, `H_f`.

| Paper column | Fresh command | Execution performed |
|---|---|---|
| Default | `make reproduce-default` | Nine native OpenROAD Diamond DPL runs |
| BO-DSE | `make reproduce-bo` | 400 public-knob trials per case, four-way parallel |
| ReviewDSE-HPWL | `make replay-reviewdse TRACK=hpwl` | Rebuild and run nine frozen selected source trees |
| ReviewDSE-GHR | `make replay-reviewdse TRACK=ghr` | Rebuild and run nine runtime-aware source trees |

`make reproduce-table4` runs all four paths and
`make summarize-table4` reads only newly generated `metrics.json`, `best.json`,
and replay `results.tsv` files. The output is
`$DPL_EVOLVE_STATE_ROOT/paper_reproduction/table4/table4-fresh.tsv`.

The 18 selected source trees are in
`artifacts/01-table4-qor/selected-programs/`. Their tree digests are checked
before every replay. The nine ODBs are regenerated by
`make prepare-paper-inputs`; generated input hashes and source revisions are
recorded. Only AES Nangate45 currently has a retained paper-time ODB hash, so
the other eight cannot yet be described as bit-identical paper inputs.
Those eight are checked as scientific reproductions: complete legal fresh
metrics are mandatory, while relative HPWL deltas and runtime ratios are
compared with explicit tolerances. Absolute HPWL drift is reported but is not
used as a false bit-exact test. AES Nangate45 retains the checksum-pinned
absolute replay check.

## Figures 4 and 5

`make reproduce-figures FIGURE_SOURCE=retained` verifies the compact author-run
logs, normalizes Figure 4 to nine complete iteration-0..10 trajectories, and
recomputes Figure 5's runtime-quality Pareto frontier from 400 BO trials per
panel plus ReviewDSE candidates. This redraws retained experimental data.

After a fresh full search and Table 4/BO run,
`make reproduce-figures FIGURE_SOURCE=fresh DSE_RUN_PREFIX=NAME` performs the
same normalization from newly generated outputs. The DSE launcher records that
prefix so the renderer cannot silently select an unrelated run.

## Ariane warm-start diagnostic

`make reproduce-ariane-diagnostic` checksum-verifies and rebuilds six exact
source trees, executes each through the complete protected flow, and derives
the four-run missed-handoff mean and two-run guided-handoff mean. This is
diagnostic evidence, not a controlled ablation. It uses a pinned-flow rebuilt
ODB because the paper-time input checksum is unavailable.

## Table 5: downstream composability counterexamples

`make reproduce-table5` prepares each dense N45 input, builds both complete
source candidates, and executes the same legalization, DPO, and final mirroring
trajectory. The fresh summarizer checks that the selected candidate improves
`H_lg` but degrades `H_f` against its full-flow reference.

The paper-time ODBs were deleted. AES DENSE and JPEG DENSE have retained
recipes, but SWERV's untracked `config_dense2.mk` is missing and the retained
handoff ODB is not an exact constraint-stage substitute. The six complete
source candidates are also missing. The known identities are recorded,
missing assets produce `BLOCKED`, and the command never substitutes the Table
5 transcription or the standard SWERV config.

## Table 6: hard cut-row legality recovery

`make reproduce-table6` decompresses nine retained cut-row DEF/Verilog pairs,
loads three retained SDC files, and executes Diamond, Negotiation, and one
frozen evolved-negotiation source under the paper's
7200-second cap. This creates 27 fresh runs. Outcomes are derived from the
OpenROAD status and `check_placement`, then compared with the paper pattern:

- ReviewDSE is legal on all nine patterns;
- fixed Diamond has one legal result and eight failures;
- fixed Negotiation has one legal result, four failures, and four timeouts.

The paper-time ODBs are neither present nor needed by this replay. The exact
Innovus `cutRow` products and one evolved source form a checksummed external
package. The public runner and package were validated with a fresh Ariane
`center_band_8` pass. Missing data blocks execution instead of reading archived
JSON as an experimental result.

## ReviewDSE search process

`make reproduce-level1 ACKNOWLEDGE_LLM_COST=yes` evaluates the three calibration
instances and freezes reviewed method evidence and complete source starts.
It writes a Markdown packet and companion JSON manifest. Level 2 refuses to
launch the paper profile unless their hash, three-case protocol, source starts,
model settings, runtime gate, and launched Student counts validate.

`make run-dse-small` executes a one-Student, one-iteration method check with a
real private source edit, rebuild, EDA evaluation, and Teacher review.
`make plan-dse-paper` prints the complete nine-target launch without API calls;
`make run-dse-paper ACKNOWLEDGE_LLM_COST=yes` launches the reported one-Teacher,
four-Student, ten-iteration protocol. The full search is cost-gated because the
paper reports 2.15B logged and 0.10B active tokens per target.

The main paper does not disclose the exact Level 1 Student breadth and the
author-time packet was not retained. The public manifest labels 50
Students/case as a reconstruction profile, not a recovered author-time value.
The public process is runnable, but exact replay of the original stochastic
Level 1 decisions would require those author-time products.

## Supporting checks that are not paper reproduction

- `make audit-archive` recomputes packaged arithmetic and source digests.
- `make evidence` is a compatibility alias for `make audit-archive`.
- `make toolchain-smoke` runs one default AES case as a build/runtime diagnostic.
- `make test` checks repository and execution-contract behavior.

These commands are useful diagnostics, but none proves the experimental claims
without the fresh commands above.

The aggregate `make reproduce-paper-results` target runs all no-LLM fresh
result paths only when both external scopes pass. It remains blocked while the
Table 5 config/source recovery is incomplete; Table 4 and Table 6 can run
independently.
`make reproduce-available-results` runs the currently executable subset: fresh
Table 4, fresh Table 6, the fresh Ariane diagnostic, and a checksummed
retained-data reconstruction of Figures 4/5. Table 5 is explicitly excluded
and remains the only blocked reported table.
`make reproduce-paper-search ACKNOWLEDGE_LLM_COST=yes` runs Level 1 and then the
full paper Level 2 search.
