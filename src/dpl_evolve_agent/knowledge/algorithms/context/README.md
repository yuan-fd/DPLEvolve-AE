# Context Cards

Context cards explain engines, donor families, or external references that
Teacher and Student may consult before choosing a mechanism.

These files are not direct implementation instructions.  If a context card
suggests a mechanism, map it to a concrete card under `legalization/` or
`dpo_refinement/` before coding.

Current cards:

- `openroad_dpl.md`: command and stage context for OpenROAD DPL.
- `nblg.md`: negotiation-based legalization background.
- `legalm2.md`: LEGALM/ALM background.
- `dreamplace_abacus.md`: Abacus donor background and boundary conditions.
