# Results

This directory holds reference results and is the target for reproduced results.

## Structure

```
results/
├── reference/     # Reference results (from paper authors) — READ-ONLY
├── reproduced/    # Results reproduced by the evaluator — GENERATED
└── tables/        # Generated tables and figures — GENERATED
```

## Important Rules

1. **Never modify `reference/`**. These are the paper's published results.
2. `reproduced/` and `tables/` are generated by `make reproduce-*` targets.
3. Generated files are in `.gitignore` — each evaluator generates their own.
4. Compare reproduced against reference using validation scripts.

## Reference Results

Reference results are provided by the paper authors and stored in `reference/`.
They include:
- Baseline HPWL values for each case and each line
- Black-box BO optimization results
- ReviewDSE (Level 2) results
- Constraint repair success/failure logs

## Expected Reproduction Tolerance

| Metric | Tolerance | Notes |
|---|---|---|
| Instance count | Exact | Synthesis must use pinned Yosys |
| Instance area | ±0.05 µm² | Floating point tolerance |
| Global HPWL | ±0.05 µm | Determined by global placer |
| Final HPWL | ±0.05 µm | Detailed placement may vary slightly |
| HPWL improvement % | ±0.1 percentage point | Aggregate metric |
