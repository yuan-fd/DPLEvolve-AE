Reviewer guide

Connect safely, then run a real paper case.

The core AE path builds OpenROAD and produces fresh detailed-placement metrics.

1. Run the console on the evaluation machine

Clone or unpack the artifact, then start the web console from the repository root. The service listens on localhost by default.

git clone https://github.com/yuan-fd/DPLEvolve-AE.git cd DPLEvolve-AE/web-demo bash start.sh

If the repository is private, accept the collaborator invitation and authenticate Git before cloning. GitHub does not provide anonymous access to private repositories.

Open it on the same machine

Visit http://127.0.0.1:8080 and keep the execution mode set to This machine.

Open it from your laptop through an SSH tunnel

Run the following command on your laptop, replacing the user and host, and keep it open. The -N option creates the tunnel without opening a remote shell. Then open http://127.0.0.1:8080 locally.

ssh -N -L 8080:127.0.0.1:8080 reviewer@evaluation-host

Do not expose the console directly to a public interface. The tunnel encrypts browser traffic and avoids adding a second authentication layer.

2. Optional: execute on a separate machine

If the console and the EDA environment are on different machines, select Another machine via SSH in the Review page and provide:

  • the SSH host, user, and port;
  • the absolute path to DPLEvolve-AE on that host;
  • either a private-key path available to the web-server process or a password.

Use Test connection first. It verifies both SSH access and the remote repository directory. Credentials are held only in server memory while queued tasks exist; they are not included in status or export responses.

3. Diagnose without changing the host

Run Doctor before building the experiment. It never installs packages or changes files.

cd DPLEvolve-AE make doctor

If Doctor reports a missing command, use the Rocky/RHEL-family suggestion on the authors' reference OS, review it in a normal SSH terminal, and ask the administrator before using sudo. The reference server has 314 GiB RAM; the console does not claim that 8/16 GiB is enough for full parallel experiments.

Suggested checklist

Minimum fresh review

  1. Test the This machine or SSH connection.
  2. Run make doctor; copy any suggested install command into a normal SSH terminal.
  3. Use Prepare one target to build the pinned environment and validate AES Nangate45.
  4. Use Run AES result to execute the default and one frozen ReviewDSE source.
  5. Inspect the new metrics.json and replay results.tsv.
  6. If resources permit, run all default, BO, and selected-program Table 4 paths.
  7. Fetch Table 6 data and run its one-row ReviewDSE check before all 27 jobs.
  8. Expect Table 5 to report BLOCKED; it is the only blocked reported table.
  9. Export the session JSON for the review record.

Expected evaluator artifacts

H_g · H_lg · H_ip · H_f · legality · displacement · runtime
