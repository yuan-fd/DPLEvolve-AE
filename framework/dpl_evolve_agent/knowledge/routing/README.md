# Routing Knowledge

Routing files are the only knowledge cards that may directly shape Teacher
route selection before a route is named.

- `case_feature_to_mechanism_route_map.md`: feature and stage-signature route
  map for the current case.
- `mechanism_reconstruction_roadmap.md`: concrete blueprint reconstruction
  steps after Teacher selects a route.
- `evidence_weighted_mechanism_priority.md`: review-time mechanism promotion
  and demotion rules.
- `runtime_light_final_hpwl_mechanism_priority.md`: runtime-aware final-HPWL
  priority guidance.
