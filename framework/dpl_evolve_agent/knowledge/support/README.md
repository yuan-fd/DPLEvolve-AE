# Support Knowledge

Support cards are on-demand evidence, mechanisms, and diagnostic notes. They
may refine a Teacher-selected route, but they should not replace the routing
map as default context.

- `case_evolution/`: supporting case-route evidence and historical lessons.
- `dpo/`: improve-placement, basin, frontier, and handoff mechanisms.
- `legalization/`: legalizer liveness and flow support.
- `legalm/`: LEGALM paper/code alignment and runtime support.
