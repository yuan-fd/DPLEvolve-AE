# Micro-Gain Trap And Elite Donors

## Agent Use

- Role: inspiration/support only. This card must not directly select a case route or override the core blueprint map.
- First map the case through `case_feature_to_mechanism_route_map.md`; then use this card only to refine a selected mechanism, risk, or failure diagnosis.
- If this card repeats a core idea, treat the core blueprint as authoritative and keep this card as background evidence.


Small strict-metric improvements are useful evidence, but they are not proof
that the DPL algorithmic framework has meaningfully improved.  Preserve them
as elite donors; do not let Teacher or students become trapped in local tuning.

## Observation Pattern

A low-density, medium-sized design produced a clean evolved candidate with:

- strict legality,
- runtime comparable to the canonical flow,
- HPWL improvement measurable but extremely small relative to total HPWL,
- changes concentrated in focused post-legal detailed improvement rather than
  a new legalization strategy.

This is useful donor evidence, not a strategic algorithmic win.

## Useful Donor Mechanism

The donor stayed close to the canonical placement path and improved a narrow
detailed-improvement frontier:

- keep a mixed frontier of displacement outliers and HPWL-regression cells,
- rank supplemental cells by cheap regression-density scoring,
- keep legality strict,
- keep runtime comparable,
- avoid broad changes when the donor is used only for elite preservation.

This mechanism is cheap and safe enough to keep as a seed, but it should not
consume all students in later rounds.

If later iterations only add telemetry, minor threshold changes, mirror
ordering, or guard-only preservation around the same donor, downgrade the line
to `elite guard` or `validated-low-ROI`.  It remains useful for comparison, but
it should not be treated as the main algorithmic route.

## What Not To Conclude

Do not conclude that the broader DPL framework is solved.  Micro-gains usually
mean the current flow has a small local opportunity, not that assignment,
legalization, or flow ordering is fundamentally better.

The strategic objective is a case-specific algorithmic change that creates a
large, explainable improvement while preserving strict legality and independent
metrics.

## Teacher Policy

Teacher should:

- preserve the best micro-gain source as an elite donor,
- keep at most one guard route on that donor in a round,
- report the gain honestly as small,
- stop assigning more quota or threshold tuning after gains flatten,
- keep at least one student on larger algorithmic changes such as flow order,
  net-aware objectives, row assignment, compaction, repair, or
  legalization/improve-placement handoff,
- require evidence that a change affects the intended stage rather than merely
  riding the elite path.

## Student Policy

Students may borrow micro-gain mechanisms, but should not spend every
iteration polishing the same heuristic.  If a small donor is used, combine it
with a more ambitious mechanism or explicitly label the attempt as
elite-preservation.
